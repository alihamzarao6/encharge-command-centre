Encharge Capital Command Centre · last updated 18 October 2026

What this is

The Command Centre is a private work tool run by Encharge Capital for its own broker and staff. It shows the business's leads, reads documents they choose, and helps draft writing. Only people with an account set up by Encharge Capital can sign in. It is not offered to the public.

Google Drive

  • When you connect Google Drive, the Command Centre asks only for access to the files you pick yourself. It never lists, searches or browses your Drive.
  • It reads a picked file only when you ask, to answer questions about it. The file itself is never copied or stored; your Drive keeps the only copy.
  • You can disconnect at any time in the Command Centre's Settings. Disconnecting withdraws its access at Google as well.

What it keeps, and for how long

  • The text read from a file is kept with the conversation for 30 days, then deleted.
  • Passages the assistant learns from a file are kept until someone removes the file in the Command Centre.
  • The Google account address that is connected, and its access key (stored encrypted), are kept until you disconnect.

The privacy policy sets out who else sees it, and why.
