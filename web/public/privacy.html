Privacy Policy

Encharge Capital Command Centre · last updated 18 October 2026

The Command Centre is a private work tool run by Encharge Capital for its own broker and staff. This page covers the Command Centre only. How Encharge Capital handles its clients' personal information in its business is set out in its main privacy policy.

What the Command Centre holds

  • Staff sign-in details: each person's email address.
  • Conversations with the assistant, and anything staff ask it to remember.
  • Text read from documents staff attach or pick from Google Drive, and from web pages they ask it to read.
  • A copy of the business's leads from its customer system (GoHighLevel).

This can include personal and financial information about Encharge Capital's clients, added by staff in the course of their work.

Google Drive

  • What it can access: only the files a person picks. It never lists, searches or browses their Drive. When it reads a picked file it receives the file's name, type, size and contents. It also receives the connected Google account's email address, so the person can see which account is connected.
  • How it is used: only to read a file when the person asks, so the assistant can answer questions about it in the Command Centre.
  • What is kept: the file itself is never copied or stored. The text read from it is kept with the conversation for 30 days, then deleted. Passages the assistant learns from it are kept until someone removes the file in the Command Centre. A record of each read (which file, its size) is deleted after 24 hours. The connected account's email address and its access key, stored encrypted, are kept until the person disconnects.
  • Who sees it: only signed-in staff who can see that conversation. To answer a question, the relevant text is sent to Anthropic (which writes the answer) and Voyage AI (which helps find the relevant passages). It is not sold, not used for advertising, and not shared with anyone else.
  • Disconnecting: in the Command Centre's Settings. It withdraws the Command Centre's access at Google and deletes the stored connection.

The Command Centre's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where it is stored and processed

  • The database is hosted by Supabase in Sydney, Australia.
  • The web pages are served by Vercel.
  • Anthropic and Voyage AI process the text they receive outside Australia, including in the United States.

How long things are kept

  • Text from attached or picked files: 30 days.
  • Text from web pages: 24 hours.
  • Passages learned from documents: until someone removes the file.
  • Conversations: until someone deletes them.
